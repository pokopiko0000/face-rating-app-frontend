# AI顔分析アプリケーション 要件定義書

## 1. プロジェクト概要

### 1.1. プロジェクト名
AI顔分析Webアプリケーション (仮)

### 1.2. プロジェクトゴール
ユーザーがアップロードした顔写真をAIが分析し、どの国の「理想顔」に近いか判定するWebアプリケーションを開発する。
最終的な目標は、SNSでの共有（バイラル）を促して多くのユーザーを集め、広告収益を最大化すること。

### 1.3. ターゲットユーザー
- **メインターゲット**: 10代〜20代の男女。特にSNS利用に積極的な層。やや女性の比率が多いことを想定。
- **セカンダリターゲット**: 30代以上の、美容や自己分析に興味がある層も気軽に使えるように配慮する。

---

## 2. デザイン・UI/UX要件

### 2.1. デザインコンセプト
**「クリーンなベースに、科学的に相性の良いカラフルなアクセントを加え、ポップさとクールさを兼ね備えた、おしゃれで洗練されたUI」**

### 2.2. 詳細なデザイン指針
- **ベースレイアウト**:
  - 背景は白またはごく薄いグレー (`#F9FAFB`) を基調とし、清潔感と開放感を出す。
  - コンテンツは中央に配置したシングルカラムレイアウトを基本とし、十分な余白を確保する。
- **アクセントと色彩**:
  - 背景の隅に、オーロラのような淡いグラデーションのぼかし（ピンク、水色、黄色など）を配置し、モダンな印象と動きを subtle に加える。
  - ボタンやアイコンには、ティール、マゼンタ、バイオレットなど、鮮やかだが品のあるアクセントカラーを限定的に使用する。
- **タイポグラフィ (フォント)**:
  - **見出し**: 洗練され、やや遊び心のあるサンセリフ体（例: `Poppins`, `Figtree`）。
  - **本文**: 可読性が高く、モダンなサンセリフ体。
- **インタラクション**:
  - ボタンのホバーエフェクトや、ローディングアニメーション、結果表示のエフェクトなどで、ユーザーが操作していて楽しいと感じる「クール」な要素を取り入れる。

---

## 3. 機能要件

### 3.1. トップページ
- ユーザーの興味を引く、印象的なキャッチコピーを配置。
- 直感的に操作できる画像アップロード機能 (クリック選択 & ドラッグ&ドロップ)。
- 「使い方」を3ステップ（写真アップロード → 性別選択 → 結果を見る）で視覚的に説明。

### 3.2. 分析待機画面
- ユーザーを飽きさせないための、クールなローディングアニメーションを実装。
- 分析中に、各国の理想顔の特徴などの「豆知識」をランダムに表示する。

### 3.3. 結果表示ページ
- 分析結果（国名、類似度など）を分かりやすく表示。最も類似度が高い国を強調する。
- **SNSでのシェアを最大限に促進するデザイン**にする。結果を一枚の「診断結果カード」のような画像として生成・保存できる機能を設ける。
- ワンクリックでTwitterやInstagramなどに共有できるボタンを設置する。

### 3.4. 必須ページ
- **プライバシーポリシーページ**: 広告掲載の必須要件。
- **利用規約ページ**

## 4. 収益化要件 (広告戦略)

### 4.1. 広告サービス
- **Google AdSense** を利用する。

### 4.2. 広告配置
ユーザー体験を著しく損なわない範囲で、以下の3箇所に広告を配置する。
1.  **トップページ**: フッター上部などに、控えめなバナー広告を設置。
2.  **分析待機画面**: 収益の柱。ローディングアニメーションと並行して、画面の一部に動画またはバナー広告を表示。
3.  **結果表示ページ**: 診断結果の下に、関連性の高い広告（美容、ファッションなど）を表示。

## 5. 技術スタック・利用サービス

「低コスト（原則無料）かつ高品質」を実現する以下の技術スタックを選定する。

| カテゴリ         | 選択サービス/ツール       | 役割・選定理由                                         |
| :--------------- | :------------------------ | :----------------------------------------------------- |
| **フロントエンド**   | **Next.js (React)**       | 高速、高機能なモダンフレームワーク。                    |
| └ **UIライブラリ** | **Tailwind CSS**          | 洗練されたUIを効率的に実装可能。                      |
| └ **ホスティング** | **Vercel**                | 無料から利用可能。Next.jsとの相性抜群で、高速・簡単。 |
| **バックエンド**     | **FastAPI (Python)**      | 開発完了済み。AIとの連携に適した高速フレームワーク。    |
| └ **ホスティング** | **Render**                | 無料プランあり。Pythonアプリのホスティングに適する。     |
| **ドメイン**       | **Cloudflare Registrar** 等 | （公開直前に取得）長期的に見て安価で高機能。           |
| **広告**           | **Google AdSense**        | 信頼性と収益性が最も高い広告ネットワーク。             |

---

## 6. プロジェクトロードマップ

1.  **フェーズ1: 開発とテスト (現在地)**
    - UI実装、バックエンド連携、レスポンシブ対応、テストを完了させる。
2.  **フェーズ2: デプロイ**
    - ドメイン取得、Vercel/Renderへのアプリケーションのアップロードを行い、サービスをインターネットに公開する。
3.  **フェーズ3: 収益化**
    - プライバシーポリシーを作成し、Google AdSenseに申請。審査通過後、広告コードを設置する。
4.  **フェーズ4: 運用・改善**
    - Google Analytics等でアクセス解析を行い、ユーザーの反応を見ながら継続的にサービスを改善・成長させる。
